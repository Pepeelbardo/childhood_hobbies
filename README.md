# My Childhood — Static Web Page

Static HTML/CSS page built as part of the HyperionDev Software Engineering
bootcamp, deployed with GitHub Pages for **Practical Task 1: Deployment of
Static Websites**.

## About this project

The page ("Hobbies") is a short, styled retrospective on four childhood
hobbies — videogames, hiking, skateboarding, and roller skating — built with
plain HTML and embedded CSS (no frameworks, no back-end, no database).

## Live site

https://Pepeelbardo.github.io/childhood_hobbies

## Project structure

```
index.html      Main page (required by GitHub Pages)
images/         Photos used on the page (royalty-free, sourced from Pexels)
boxModel/       Small standalone CSS box-model practice exercise
```

## Tech

- HTML5
- CSS3 (embedded in `index.html`)

## Deployment

Hosted for free with [GitHub Pages](https://pages.github.com/), served
directly from the `main` branch of this public repository.
